개인정보처리방침

최종 수정: 2026년 10월 21일

이 방침은 ASTRA TACTICS와 이 지원 웹사이트에서 정보가 처리되는 방식을 설명합니다. 문의와 개인정보 관련 요청은 아래 개발자 이메일로 보내실 수 있습니다.

1. 게임에서 처리하는 정보

ASTRA TACTICS는 계정이나 로그인을 요구하지 않으며 광고, 추적 또는 분석 SDK를 포함하지 않습니다. 개발자는 게임을 통해 플레이 활동, 기기 식별자나 위치를 수집하지 않으며 플레이어 정보를 위한 서버를 운영하지 않습니다.

2. 저장 데이터와 설정

게임 진행 상황과 설정은 기기에 저장됩니다. 운영체제 백업에는 기기 설정과 Apple 정책에 따라 앱 데이터가 포함될 수 있습니다. App Store 구매와 결제 정보는 Apple이 처리하며 개발자는 카드 정보를 받지 않습니다.

3. 문의할 때 보내는 정보

이메일로 문의하면 개발자는 이메일 주소, 문의 내용과 사용자가 선택하여 보낸 첨부파일을 받습니다. 이 정보는 문의 응답과 문제 해결에 사용하며 광고에 사용하지 않습니다. 이메일은 Google 정책이 적용되는 Gmail로 처리합니다. 민감한 정보는 보내지 마세요.

4. 보관 및 사용자의 선택

문의 기록은 요청 처리, 문제 후속 대응 또는 적용되는 법적 의무 이행에 필요한 동안만 보관합니다. 보내신 정보의 열람·정정·삭제는 아래 이메일로 요청하실 수 있습니다. 기기의 앱 데이터 관리 기능이나 앱 삭제를 통해 기기에 저장된 게임 데이터를 제거할 수 있습니다.

5. 웹사이트와 외부 서비스

이 정적 웹사이트는 GitHub Pages에 호스팅됩니다. GitHub는 보안을 위해 방문자의 IP 주소를 기록합니다. 개발자는 분석 도구, 광고 추적기나 쿠키를 추가하지 않습니다. 이메일이나 외부 링크를 열면 선택한 이메일 서비스, GitHub 또는 Apple의 정책이 적용됩니다.

6. 아동과 방침 변경

게임은 아동에게 개인정보를 요청하지 않습니다. 아동이 문의 과정에서 개인정보를 보냈다면 부모 또는 보호자가 삭제를 요청할 수 있습니다. 정보 처리 방식이 변경되면 방침을 갱신하며 상단 날짜로 현재 버전을 안내합니다.
