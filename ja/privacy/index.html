プライバシーポリシー

最終更新：2026年10月21日

本ポリシーは、ASTRA TACTICS とこのサポートサイトでの情報の取り扱いを説明します。ご質問や個人情報に関するご依頼は、下記の開発者メールアドレスまでお送りください。

1. ゲーム内の情報

ASTRA TACTICS はアカウントやログインを要求せず、広告、追跡、分析 SDK を含みません。開発者はゲームを通じてプレイ履歴、端末識別子、位置情報を収集せず、プレイヤー情報を保存するサーバーを運営しません。

2. 進行状況と設定

進行状況と設定は端末内に保存されます。OS のバックアップには、端末の設定と Apple のポリシーに従ってアプリデータが含まれる場合があります。App Store の購入と決済は Apple が処理し、開発者がカード情報を受け取ることはありません。

3. お問い合わせ時の情報

メールでお問い合わせいただくと、メールアドレス、本文、ご自身で送信した添付ファイルを開発者が受け取ります。これらは回答と問題解決のために使用し、広告には使用しません。メールは Google のポリシーに従う Gmail で処理します。機微な情報は送らないでください。

4. 保存期間と利用者の選択

お問い合わせの記録は、対応、問題のフォローアップ、または適用される法的義務に必要な間のみ保存します。送信した情報の開示、訂正、削除は下記メールでご依頼いただけます。端末内のゲームデータは、端末のアプリデータ管理機能またはアプリの削除で消去できます。

5. ウェブサイトと外部サービス

この静的サイトは GitHub Pages で公開しています。GitHub はセキュリティのため訪問者の IP アドレスを記録します。開発者は分析ツール、広告トラッカー、Cookie を追加しません。メールや外部リンクを開く際には、選択したメールサービス、GitHub、Apple のポリシーが適用されます。

6. お子様とポリシーの更新

ゲームはお子様に個人情報を求めません。お子様がサポートへ個人情報を送った場合、保護者は削除を依頼できます。情報の取り扱いが変わった場合は本ポリシーを更新し、上記の日付で最新版を示します。
