隱私權政策

最後更新：2026年10月21日

本政策說明 ASTRA TACTICS 與本支援網站如何處理資訊。如有疑問或隱私相關請求，請聯絡下方的開發者電子郵件。

1. 遊戲中的資訊

ASTRA TACTICS 不需要帳號或登入，也不包含廣告、追蹤或分析 SDK。開發者不會透過遊戲收集遊玩活動、裝置識別碼或位置資訊，亦不營運玩家資料伺服器。

2. 進度與設定

遊戲進度與偏好設定儲存在裝置本機。作業系統備份可能依裝置設定與 Apple 政策包含應用程式資料。App Store 購買與付款資訊由 Apple 處理，開發者不會收到信用卡資料。

3. 聯絡支援時

透過電子郵件聯絡時，開發者會收到您的電子郵件地址、內容及您選擇寄送的附件。這些資訊僅用於回覆與解決問題，不用於廣告。郵件透過適用 Google 政策的 Gmail 處理。請勿寄送敏感資訊。

4. 保存與您的選擇

支援紀錄僅在處理請求、跟進問題或履行適用法律義務所需期間保存。您可透過下方電子郵件申請查閱、更正或刪除所提供的資訊。本機遊戲資料可透過裝置的應用程式資料管理功能或刪除應用程式移除。

5. 網站與外部服務

本靜態網站由 GitHub Pages 託管。GitHub 會基於安全目的記錄訪客 IP 位址。開發者不加入分析工具、廣告追蹤器或 Cookie。開啟電子郵件或外部連結時，將適用所選郵件服務、GitHub 或 Apple 的政策。

6. 兒童與政策更新

遊戲不會要求兒童提供個人資訊。若兒童曾寄送個人資訊給支援，家長或監護人可要求刪除。資訊處理方式改變時會更新本政策，上方日期代表目前版本。
