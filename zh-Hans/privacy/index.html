隐私政策

最后更新：2026年10月21日

本政策说明 ASTRA TACTICS 与本支持网站如何处理信息。如有疑问或隐私相关请求，请联系下方的开发者电子邮件。

1. 游戏中的信息

ASTRA TACTICS 不需要账号或登录，也不包含广告、跟踪或分析 SDK。开发者不会通过游戏收集游玩活动、设备标识符或位置信息，也不运营玩家资料服务器。

2. 进度与设置

游戏进度与偏好设置保存在设备本地。操作系统备份可能根据设备设置与 Apple 政策包含应用数据。App Store 购买与付款信息由 Apple 处理，开发者不会收到银行卡信息。

3. 联系支持时

通过电子邮件联系时，开发者会收到您的电子邮件地址、内容及您选择发送的附件。这些信息仅用于回复与解决问题，不用于广告。邮件通过适用 Google 政策的 Gmail 处理。请勿发送敏感信息。

4. 保存与您的选择

支持记录仅在处理请求、跟进问题或履行适用法律义务所需期间保存。您可通过下方电子邮件申请查阅、更正或删除所提供的信息。本地游戏数据可通过设备的应用数据管理功能或删除应用移除。

5. 网站与外部服务

本静态网站由 GitHub Pages 托管。GitHub 会基于安全目的记录访客 IP 地址。开发者不加入分析工具、广告跟踪器或 Cookie。打开电子邮件或外部链接时，将适用所选邮件服务、GitHub 或 Apple 的政策。

6. 儿童与政策更新

游戏不会要求儿童提供个人信息。如果儿童曾发送个人信息给支持，家长或监护人可要求删除。信息处理方式改变时会更新本政策，上方日期代表当前版本。
