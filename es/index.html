Contactar con el desarrollador

¿Encontraste un problema o tienes alguna pregunta? Envía un correo con los datos que se indican a continuación.

Enviar un correo ↗

Qué datos incluir

  1. 01Modelo del dispositivo y versión de iOS o iPadOS
  2. 02Versión de la aplicación y lugar donde ocurrió el problema
  3. 03Pasos para reproducir el problema
  4. 04Una captura de pantalla, si resulta útil; elimina primero la información personal

Antes de escribirnos

¿Tienes un problema con una compra o un cobro?

Apple gestiona los pagos del App Store y las solicitudes de reembolso. Visita la página de soporte de Apple para compras.

Soporte de Apple para compras

¿Tienes un problema con el progreso o los ajustes?

Describe qué estabas haciendo y el último momento en que todo funcionaba. Las partidas y los ajustes se guardan en tu dispositivo. No elimines la aplicación mientras intentamos resolver el problema: podrías perder los datos locales.

¿Necesito una cuenta?

No necesitas una cuenta ni iniciar sesión. El juego es una aplicación de pago sin publicidad.
